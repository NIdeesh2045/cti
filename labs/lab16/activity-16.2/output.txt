------------------------------------------------------------
3. FRAUD QUERY SERVICE
------------------------------------------------------------

Implemented FraudQueryService with the following methods:

1. get_transaction(txn_id)
   Retrieves transaction information from MongoDB.

2. get_user_profile(user_id)
   Retrieves user event history from Cassandra.

3. detect_fraud_rings(user_id, max_hops)
   Detects connected users through Neo4j graph traversal.

4. analyze_fraud(txn_id, user_id)
   Combines results from all three databases.

------------------------------------------------------------
4. CONNECTION POOLING AND CIRCUIT BREAKER
------------------------------------------------------------

Connection pooling:
- MongoDB maximum pool size: 10
- Neo4j maximum connection pool size: 10
- Cassandra cluster connection management.

Circuit breaker:
- Failure threshold: 3 consecutive failures.
- Reset timeout: 30 seconds.
- Prevents repeated calls to an unavailable backend.
- Allows retry after the reset timeout.
