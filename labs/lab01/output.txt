ACTIVITY 1.1 - CLASSIFY DATABASE PRODUCTS
==========================================================================================

Product     : Amazon S3
Family      : Key-Value (Object Storage)
Reason      : Objects are stored and retrieved using unique object keys.
Best For    : Storing images, videos, backups and data lakes.
Limitation  : Does not support database-style queries on object contents.
------------------------------------------------------------------------------------------

Product     : Couchbase
Family      : Document
Reason      : Stores JSON documents and supports queries and indexes on fields.
Best For    : User profiles, product catalogs and session management.
Limitation  : Requires careful indexing and memory management.
------------------------------------------------------------------------------------------

Product     : Apache HBase
Family      : Wide-Column
Reason      : Organizes distributed data into column families and supports wide rows.
Best For    : Large-scale log storage and time-series workloads.
Limitation  : Complex administration and limited relational-style querying.
------------------------------------------------------------------------------------------

Product     : Amazon Neptune
Family      : Graph
Reason      : Stores relationships as graph structures and supports graph queries.
Best For    : Fraud detection, recommendation engines and social networks.
Limitation  : Not ideal for simple key-based lookups or ordinary tabular workloads.
------------------------------------------------------------------------------------------

Product     : Memcached
Family      : Key-Value
Reason      : Stores values as byte arrays accessed through unique string keys.
Best For    : Caching web sessions and frequently requested database results.
Limitation  : In-memory cache with no built-in durable data storage.
------------------------------------------------------------------------------------------

TRY IT YOURSELF - ADDITIONAL PRODUCT
==========================================================================================
Product     : ScyllaDB
Family      : Wide-Column
Reason      : ScyllaDB uses a distributed wide-column data model compatible with Apache Cassandra.
Best For    : High-throughput workloads such as IoT data and event storage.
Limitation  : Requires data modelling around partition keys and query patterns.
