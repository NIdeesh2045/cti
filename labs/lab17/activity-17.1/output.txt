BUILDING A SIMPLE RAG PIPELINE
============================================================

OBJECTIVE:
To build a Retrieval-Augmented Generation (RAG) pipeline
that stores documents, retrieves relevant information using
vector search, and generates responses using an LLM.

------------------------------------------------------------
1. TECHNOLOGIES USED
------------------------------------------------------------

Python: Application development
MongoDB Atlas: Document and vector storage
Voyage AI: Text embedding generation
Atlas Vector Search: Semantic document retrieval
Ollama: Local LLM execution
Llama 3.2 (3B): Response generation
PyMongo: MongoDB connectivity

------------------------------------------------------------
8. COMPLETE RAG PIPELINE
------------------------------------------------------------

Workflow:

User Question
     |
     v
Voyage AI Embedding Generation
     |
     v
MongoDB Atlas Vector Search
     |
     v
Retrieve Top 3 Relevant Documents
     |
     v
Construct Prompt with Retrieved Context
     |
     v
Ollama - Llama 3.2 (3B)
     |
     v
Generate AI Response
     |
     v
Store Conversation in MongoDB

------------------------------------------------------------
9. CONCLUSION
------------------------------------------------------------

The RAG pipeline was successfully implemented using
MongoDB Atlas, Voyage AI and Ollama.

Documents were divided into chunks and converted into
1024-dimensional embeddings.

MongoDB Atlas Vector Search retrieved the three most
relevant document chunks for user queries.

Ollama with the Llama 3.2 (3B) model generated responses
using the retrieved context.

Conversation memory was implemented using MongoDB to
maintain the last five messages for multi-turn interactions.

The activity demonstrates how Retrieval-Augmented
Generation combines semantic search and language models
to provide context-aware responses.
